# CIVIC WATCH v0.9 — National City Foundation

- Adds a 20-city launch directory in `api/cities.json`, exposed through `GET /api/cities?q=`.
- Adds a city dropdown to `/map`; selecting a city changes map center and reloads only that city's reviewed map records.
- `GET /api/map/features?city=<id>` returns reviewed GeoJSON records scoped by city. Unknown cities return HTTP 404.
- Curated records must include `properties.city_id` matching a directory city. Existing publication safeguards for verified sources, historical aggregation, and generalized surveillance areas remain in effect.
- No paid provider, live ingestion, or new database has been provisioned. The directory contains city centers for navigation only; it is not a comprehensive nationwide cities catalog or a geographic boundary dataset.
- The dataset remains empty until licensed sources and human-reviewed records are added. City listing does not imply data coverage.

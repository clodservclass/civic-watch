# CIVIC WATCH v0.4 — Surveillance transparency preview

## Mission
Explain how networked surveillance can generate movement-pattern inferences, while holding institutions accountable through verifiable public records.

## Included
- `/mirror`: interactive, fictional four-observation simulation on an abstract grid; no actual camera locations, license plates, identifiers, or telemetry.
- `/surveillance/registry`: empty registry preview and publication standards, with no unverified locations.
- Read-only v0.3 public records API and demo dashboard unchanged.
- Dockerfile includes new pages, and tests assert educational/synthetic labeling.

## Not yet included
- No real surveillance registry data, public records ingest, data-sharing graph, or reviewer workflow.
- No public submissions, evidence uploads, live officer/ICE location tracking, or individual identification.
- The v0.3 database migration is still a separate deployment step and has not been provisioned.

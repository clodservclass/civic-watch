# CIVIC WATCH v0.8 — Public Information Map

## Features
- `/map` — MapLibre geographic map with four independently toggled layers: road closures, traffic incidents, historical public-safety aggregates, and verified surveillance programs.
- `/api/map/features` — read-only GeoJSON endpoint. Reads only the reviewed, curated file `api/public_map_records.geojson`. No external API calls or secrets.
- The curated dataset is intentionally empty. No invented real-world records are published. The older synthetic demonstration remains at `/demo/incidents` and the abstract coverage simulator remains at `/coverage`.

## Data ingestion and provenance
No commercial API or Waze partnership is configured. Before adding a provider, obtain permission, check license/redistribution and retention terms, add attribution, and review individual records. Possible licensed traffic incident providers include HERE and TomTom; verify current documentation and terms before implementing.

Only editorially approved GeoJSON features are published. Required properties: `layer` (closures/incidents/historical/surveillance), `title`, `source_name`, `source_url` (HTTPS), `data_status` (verified), `reviewed_at` (ISO timestamp). `observed_at` is optional for road disruptions and surveillance programs; required for historical activity. Historical activity must be delayed at least 7 days and aggregated. Surveillance features must be generalized Polygon or MultiPolygon areas, never point camera locations, coverage cones, blind spots, or live sensor ranges. No police/ICE officer locations, personnel movements, individual license plates, or individual travel histories.

This is a **publication contract**, not an ingestion pipeline. Future work: build provider adapters, scheduled import jobs, geocoding, automated license checks, audit logging, editorial approvals, and stale-data expiry. The API rejects malformed or unsafe curated data rather than silently publishing it. Public traffic data should also have freshness and provenance review before approval.

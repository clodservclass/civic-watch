# CIVIC WATCH v0.2 — Staging preview

## Changes
- Responsive dark operations dashboard with category navigation.
- CARTO dark raster basemap in MapLibre; OpenStreetMap/CARTO attribution included. Third-party tiles and MapLibre assets require internet access.
- Synthetic police, immigration accountability, and surveillance records; filterable timeline and markers.
- `/health` reports v0.2, `/ready` checks optional database connectivity, `/incidents` remains empty and read-only.
- Automated tests for labels, filters' underlying API, health, and disabled write endpoints.

## Important limitations
- **All map points are fictional and intentionally not real reports.**
- Database schema exists, but Railway PostGIS has not been provisioned and the public incident API does not query it yet.
- Public submissions and evidence uploads remain disabled. No precise live officer or enforcement tracking.
- The dashboard is a prototype, not a verified public incident information service.

## Deploy safely
1. Wait for GitHub Actions tests to pass.
2. Review PR changes, then merge into the branch configured in Railway (`feature/v0.1-staging` currently), or explicitly update Railway's branch to `feature/v0.2-dashboard` for staging.
3. Check `/health` returns version `0.2.0`, `/demo/incidents` is labeled synthetic, and the map renders streets.
4. Keep the Railway domain target port equal to the actual Uvicorn port (previously 8080).
5. Do not enable production auto-deploy, new paid resources, or real public data without separate approval.
